# El rincón de matemáticas

Web del canal de YouTube *El rincón de matemáticas*, de José Antonio Ibáñez.
Publicada con GitHub Pages.

## ⚠️ Bachillerato por unidades
Después de regenerar la web con `build.py`, ejecutar `python3 herramientas/bach_unidades.py` (coloca los vídeos de Bachillerato en sus unidades). Si no, se pierde esa organización.
