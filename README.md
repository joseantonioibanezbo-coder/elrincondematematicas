Publicada con GitHub Pages.

## ⚠️ Bachillerato por unidades
Desde el 20 nov 2026 (23:45) la lógica de `herramientas/bach_unidades.py` está integrada al final de `build.py` (guardado en el Taller, `taller/web/build.py.txt`): basta con `python3 build.py <carpeta>`. El script suelto se queda solo como referencia; si se ejecuta después, detecta que Bachillerato ya está por unidades y no hace nada.
Antes de regenerar la web: `git pull` y usar el `build.py` del Taller. Si un chat cambia `build.py`, debe guardarlo en el Taller.
