Ver los tres retos

Tres retos para quien ya domina la unidad y quiere pensar un poco más. Inténtalo antes de abrir la solución.

  1. 🧩 Ingenio
    En una progresión aritmética, a₅ + a₆ = 30. Sin calcular a₁ ni d, ¿cuánto vale la suma de los 10 primeros términos? Después, escribe dos progresiones distintas que lo cumplan.
    Ver solución
    Los términos de S₁₀ se emparejan como hizo Gauss: a₁ + a₁₀ = a₂ + a₉ = … = a₅ + a₆, porque al avanzar un puesto se suma d y al retroceder otro se resta d. Con el término general: a₅ + a₆ = (a₁ + 4d) + (a₁ + 5d) = a₁ + (a₁ + 9d) = a₁ + a₁₀.
    Entonces a₁ + a₁₀ = 30 y S₁₀ = (a₁ + a₁₀)·10 / 2 = 30·5 = 150.
    Ejemplos: a₁ = 6 y d = 2 (6, 8, …, 14, 16, …) o a₁ = −3 y d = 4 (−3, 1, …, 13, 17, …). Las dos suman 150.
  2. 🔍 Investiga
    Suma los primeros números impares: 1, 1 + 3, 1 + 3 + 5, 1 + 3 + 5 + 7, …
    a) ¿Qué números salen? Haz una conjetura: ¿cuánto suman los n primeros impares?
    b) Demuéstrala con la fórmula de Sₙ.
    c) ¿Cuántos impares seguidos, empezando por el 1, hay que sumar para pasar de 1000? ¿Cuál es el último?
    Pista: dibuja con puntos un cuadrado de 2×2, de 3×3… ¿Qué añades cada vez?
    Ver solución
    a) Salen 1, 4, 9, 16, …: los cuadrados. Conjetura: 1 + 3 + 5 + … (n impares) = n². En el dibujo, para pasar del cuadrado n×n al (n + 1)×(n + 1) se añade una «L» de 2n + 1 puntos: el siguiente impar.
    b) Los impares forman una progresión aritmética con a₁ = 1 y d = 2: aₙ = 1 + (n − 1)·2 = 2n − 1. Sₙ = (1 + 2n − 1)·n / 2 = 2n·n / 2 = n².
    c) Buscamos n² > 1000: 31² = 961 no llega y 32² = 1024 sí. Hacen falta 32 impares y el último es a₃₂ = 2·32 − 1 = 63.
  3. ✨ Curiosidad · Gauss
    Los números triangulares cuentan los puntos de un triángulo: 1, 3, 6, 10, … Es decir, Tₙ = 1 + 2 + … + n.
    a) Con el truco de Gauss, halla una fórmula para Tₙ y calcula T₁₀₀.
    b) Comprueba con varios valores que 8·Tₙ + 1 es siempre un cuadrado perfecto. Después, demuéstralo.
    c) El 10 de julio de 1796, con 19 años, Gauss escribió en su diario «¡EUREKA! num = Δ + Δ + Δ»: todo número natural es suma de tres números triangulares (vale el 0). Escribe así el 20, el 31 y el 50. ✨ La historia de Gauss
    Ver solución
    a) Es una progresión aritmética con a₁ = 1 y d = 1: Tₙ = (1 + n)·n / 2. T₁₀₀ = 101·100 / 2 = 5050, la suma de Gauss.
    b) n = 1: 8·1 + 1 = 9 = 3². n = 2: 8·3 + 1 = 25 = 5². n = 3: 8·6 + 1 = 49 = 7². En general: 8·n(n + 1)/2 + 1 = 4n² + 4n + 1 = (2n + 1)², el cuadrado de un binomio.
    c) Triangulares: 0, 1, 3, 6, 10, 15, 21, 28, 36, 45, … → 20 = 10 + 10 + 0, 31 = 21 + 10 + 0 (o 28 + 3 + 0) y 50 = 28 + 21 + 1.

🚀 Para ir más allá

Ver los tres retos

Tres retos para quien ya domina la unidad y quiere pensar un poco más. Inténtalo antes de abrir la solución.

  1. 🧩 Ingenio
    Sin desarrollar, ¿cuánto suman todos los coeficientes de P(x) = (2x − 1)⁵ · (x + 1)³? ¿Y cuánto vale su término independiente?
    Ver solución
    La suma de los coeficientes es el valor numérico en x = 1: P(1) = (2 − 1)⁵ · (1 + 1)³ = 1 · 8 = 8.
    El término independiente es el valor numérico en x = 0: P(0) = (−1)⁵ · 1³ = −1.
  2. 🔍 Investiga
    Multiplica cuatro números naturales consecutivos y súmale 1: 1·2·3·4 + 1, 2·3·4·5 + 1, 3·4·5·6 + 1, …
    a) ¿Qué tipo de números salen?
    b) Demuestra que x·(x + 1)·(x + 2)·(x + 3) + 1 = (x² + 3x + 1)². Pista: multiplica primero el primero por el último y los dos del medio.
    Ver solución
    a) 25 = 5², 121 = 11², 361 = 19²: cuadrados perfectos.
    b) x·(x + 3) = x² + 3x y (x + 1)·(x + 2) = x² + 3x + 2. Llamando t = x² + 3x: t·(t + 2) + 1 = t² + 2t + 1 = (t + 1)² = (x² + 3x + 1)². Por ejemplo, con x = 3: 3² + 9 + 1 = 19.
  3. 🎓 Avance · 4º ESO
    En 4º ESO trabajarás con fracciones algebraicas, que se simplifican igual que las numéricas: factorizando y tachando factores comunes. Simplifica:
    a) (x² − 9) / (x² + 6x + 9)    b) (2x³ − 8x) / (x² − 4x + 4)
    Comprueba cada resultado dando a x el valor 1.
    Ver solución
    a) (x − 3)·(x + 3) / (x + 3)² = (x − 3) / (x + 3). Con x = 1: (1 − 9)/16 = −1/2 y (1 − 3)/4 = −1/2 ✓.
    b) 2x·(x² − 4) / (x − 2)² = 2x·(x − 2)·(x + 2) / (x − 2)² = 2x·(x + 2) / (x − 2). Con x = 1: (2 − 8)/1 = −6 y 2·3/(−1) = −6 ✓.
